## Governing sources

The native, NASA-compatible angular and static finite-cone policies remain
separate. NASA's
[lunar shadow description](https://eclipse.gsfc.nasa.gov/LEcat5/shadow.html)
governs the cited atmospheric angular prescription; it does not make the
static finite-cone sensitivity model NASA-compatible. The
[NAIF SPK specification](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/spk.html)
governs type-2 record semantics. NASA's
[hybrid catalog](https://eclipse.gsfc.nasa.gov/SEcat5/SEhybrid5a.html)
defines its A–T–A, T–A and A–T sequences. A source's published classification
does not supply a completeness proof for Moira's different model.
