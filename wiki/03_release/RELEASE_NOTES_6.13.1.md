# Release Notes - Moira 6.13.1

**Release date:** 9 November 2026.

This is the first published release of the 6.13 line. Version 6.13.0 was tagged,
but its release workflow stopped at a metadata check and nothing was built or
uploaded, so upgrades from 6.12.1 receive every 6.13.0 change here.

The features are described in the [6.13.0 release notes](RELEASE_NOTES_6.13.0.md):
five house systems, the Zariel correction, grading for 36 of 37 named patterns
and every generated harmonic layout, adjustable pattern orbs, family names for
harmonic layouts, and the native planetary routing fixes. Read the
[compatibility notes](COMPATIBILITY_NOTES_6.13.1.md) before upgrading.

The only change after the 6.13.0 tag is the Light Box inventory's record of the
REST schema renderer, which moves to Pydantic 2.14.3.
